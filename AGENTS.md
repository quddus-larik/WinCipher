# AGENTS.md

## Stack
- Tauri 2 desktop app, Windows-only: React 19 + TypeScript 6 + Vite 8 frontend, Rust backend in `src-tauri/`.
- Use `pnpm` only; the lockfile and Tauri `beforeDevCommand`/`beforeBuildCommand` depend on it.
- Tailwind CSS v4 via `@tailwindcss/vite`. Theme tokens live in `src/App.css` (`@theme`); there is no `tailwind.config` file — do not add one.
- UI primitives are shadcn `aria-mira` style (`components.json`), built on `react-aria-components`, not Radix. Icons are Hugeicons.
- `@/*` maps to `src/*` in Vite and TypeScript. `opencode.json` wires the shadcn and Hugeicons MCP servers for adding UI/icons.

## Commands
- `pnpm tauri dev` — full app; it starts Vite itself. Do not run `pnpm dev` at the same time (fixed port `1420`, `strictPort`).
- `pnpm build` — `tsc && vite build`; passes today. README/CONTRIBUTING notes about `TS5101`/`baseUrl` are stale (`tsconfig.json` has no `baseUrl`).
- `pnpm exec tsc --noEmit` — frontend typecheck. `pnpm exec vite build` builds without typechecking.
- `cargo check` / `cargo test` inside `src-tauri/` — Rust checks, including the single audio round-trip test in `lib.rs`.
- No lint or formatter scripts are configured.

## Architecture
- Frontend entry: `src/main.tsx` -> `src/App.tsx`. Drag/drop state lives in `src/hooks/use-file-upload.ts`; table and row/batch actions in `src/components/file-list-table.tsx`.
- Backend entry: `src-tauri/src/main.rs` -> `win_cipher_lib::run()` in `src-tauri/src/lib.rs`. Registered commands: `convert_image`, `convert_audio`, `convert_document`, `save_converted_files`, `discard_converted_file`.
- Document conversion: `rwml` reads `.doc`/`.docx` and exports Markdown, HTML, and a fresh DOCX; `docxide-pdf` renders DOCX to PDF with `dxpdf` as fallback. `office_oxide` is declared but unused.
- Converted bytes stay in the in-memory `ConversionState` keyed by a frontend-provided id until saved. `save_converted_files` opens the native folder picker and writes unique filenames. Keep per-row **Convert** then **Save**, footer **Convert all** then **Save all**, and busy-state disabling.
- Format matrix and aliases: `src/config/data.ts`, `src/lib/image-utils.ts`, `src/lib/audio-utils.ts`, `src/lib/document-utils.ts`, `src/lib/file-utils.ts`. Only matrix-supported targets are offered.

## Gotchas
- `tauri.conf.json` sets `"decorations": false` (custom title bar in `src/components/title-bar.tsx`) and `"dragDropEnabled": false` (required for HTML5 drag/drop in the Windows webview). Window minimum is 800x600; right-click is globally disabled in `src/App.tsx`.
- Vite ignores `src-tauri/**`; restart `pnpm tauri dev` after Rust or Tauri config changes.
- `react-aria-components` tables differ from shadcn defaults: `TableHeader` contains `TableHead` columns and `TableBody` contains `TableRow`/`TableCell`. Use RAC props (`isDisabled`, `isRowHeader`, `defaultSelectedKey`), not Radix-style props.
- UI primitives import `{ cn } from "cn"` directly; `src/lib/utils.ts` only re-exports it.
- Audio output is limited to WAV/FLAC/MP3/AAC/M4A/AIFF. M4A depends on the `esds` SLConfigDescriptor patch (`fix_m4a_esds_sl_config`); removing it produces files some players reject.
- HEIC/HEIF pass upload filtering but `convert_image` rejects them and the image matrix has no HEIC entry.
- `office_oxide` is declared in `Cargo.toml` but unused; document conversion uses `rwml`, `docxide-pdf`, and `dxpdf`.
- Versions are duplicated: `package.json` and `src-tauri/tauri.conf.json` use `1.1.x`, while `src-tauri/Cargo.toml` uses `0.1.x`. Bump all three together.

## Updater
- `src/components/title-bar.tsx` runs `check()` on startup and shows **Update now** only when an update exists; the button calls `downloadAndInstall()` then `relaunch()`. On Windows the installer exits the app during install, so relaunch only matters on other platforms.
- An update is accepted only when the `tauri.conf.json` `pubkey` matches the signing key and the `latest.json` version is strictly greater than the installed version.
- `pnpm tauri build` needs `TAURI_SIGNING_PRIVATE_KEY` (and its password) exported in the same shell. It writes installers plus `.sig` files under `src-tauri/target/release/bundle/{nsis,msi}/`; `latest.json` is not generated by the build, so copy each `.sig` contents into it by hand.
